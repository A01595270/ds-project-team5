### Funcionamiento de uv

Para agregar paquetes a uv

```
uv add paquete
```

Para agregar paquetes en grupos

```
uv add --group nombre_del_grupo paquete
```


Para actualizar grupos

```
uv sync --groups nombre_del_grupo
```



Para actualizar grupos

```
uv sync --groups nombre_del_grupo
```


Para actualizar todos los grupos

```
uv sync --all-groups
```
